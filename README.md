# Расписание

Минимальный сайт на HTML, CSS и JavaScript. Для запуска из папки проекта:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000` в браузере. Сервер нужен потому, что браузер не разрешает загружать JSON через `fetch` при прямом открытии `index.html`.

## Данные

- `data/base-schedule.json` — общее расписание для всей группы.
- `data/language-schedule.json` — иностранные языки. У занятия указываются `day`, `time`, необязательные `end`, `cab` и `GroupId`; `time: 15` означает начало в 15:00, а `end: 16` — окончание в 16:00.
- `data/physical-education.json` — физкультура. У записи указываются `Username`, `Type`, `day`, `time`, а при необходимости — `end` и `room`.

В файлах персонального расписания записи находятся в массиве `users`, чтобы можно было добавить нескольких студентов. Скрипт также понимает исходный вариант с одним объектом пользователя без массива.

Все занятия занимают один часовой слот: `HH:00–HH:50`; следующие 10 минут — перерыв. У базовых пар `end` обозначает час окончания: например, `start: 8, end: 10` — два слота, в 8:00 и 9:00.

Ширина столбцов и минимальная высота ячеек настраиваются в начале `styles.css` через переменные `--time-column-width`, `--day-column-width` и `--lesson-min-height`.
